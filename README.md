# LettuceLovesBanana 🍌🥬

After Dark Shuffle: an iPhone-friendly couples challenge game.

## Publish the site

1. Open [GitHub Pages settings](https://github.com/Saudioseas/LettuceLovesBanana/settings/pages).
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main**, select **/(root)**, and tap **Save**.
4. After GitHub Pages deploys, open https://saudioseas.github.io/LettuceLovesBanana/ in Safari.
5. Tap **Share → Add to Home Screen** on each iPhone.

## Privacy

Each person can add, edit and save their own challenges independently on their own phone. They are stored locally, not in GitHub. Your game website is publicly accessible, even though each device's saved list is private. Export backups before deleting the Home Screen app or clearing site data. This is not a synced two-person database.
